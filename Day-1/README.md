## 🎯 Learning Objectives

1. Verify Python 3 and the editor (IDLE / VS Code) are working properly.
2. Use Python's interactive shell (`>>>`) as a quick computational tool.
3. Write, save, and run a standalone script file (`.py`).
4. Master `print()` statements for text strings, multi-line blocks, and mathematical calculations.
5. Practice adding single-line documentation comments (`#`).
6. Identify and resolve common beginner syntax errors.

---

## 📋 Activity Roadmap

### Part 1: Interactive Shell Warm-up (10 mins)

Open terminal or IDLE shell and execute:

```python
>>> print("Hello from Python 3!")
>>> 2 ** 8                         # 256 (number of values in 1 byte)
>>> 1024 * 1024                    # 1,048,576 (bytes in 1 MB)
>>> 16 * 1024 * 1024 * 1024        # Bytes in 16 GB RAM
```

### Part 2: The Script Challenge (20 mins)

Open [`starter_profile.py`](file:///Users/dipenparihar/Documents/CBC/Python-5-Oct/Day-1/starter_profile.py) and customize it:

1. Fill in header comments (`#`) with your name and date.
2. Build decorative border lines (`=` or `*`).
3. Print your personal profile info.
4. Add a multi-line quote using `'''` or `"""`.
5. Compute and print at least two mathematical calculations directly inside `print()`.

Run the file to verify your output:

```bash
python3 starter_profile.py
```
